## Potato types

| Variety                                  | Description                                                                      | Uses                          | Names                   |
|------------------------------------------|----------------------------------------------------------------------------------|-------------------------------|-------------------------|
| -Starchy / Floury <br/> -Mehligkochend <br/> -Varný Typ C     | High in starch, low in moisture, cook fast, fall apart easily. Thick rough skin. | Frying, baking, mashed                | Russets, most sweet potatoes, Jewel Yam, Japanese Sweet |
| -Waxy <br/> -Festkochend <br/> -Varný Typ A                   | Lower starch, higher moisture, smaller, hold together. Shiny waxy thin skin.     | Roasting, boiling, salads     | Fingerlings, Red Bliss, French Fingerling, Russian Banana |
| -All purpose <br/> -Vorwiegend festkochend <br/> -Varný Typ B | An all purpose potato, between starchy and waxy. Good generic potatoes.          | Pan-frying, roasting, stewing, mashed | Yukon Gold, Red Gold, All Blue, Purple Majesty |
